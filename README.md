# S K SOLUTIONS — Ryoto showroom

Open `index.html` in a modern browser. Plain HTML and CSS; no build step, JavaScript or external asset requests.

The page contains a dark ATOM PRO showcase, four featured scooters, an expandable collection of sixteen models and the supplied Patna showroom address. Every model's **View details** button opens its specifications in a native HTML popover on the same page. Close with the close button, Escape or a click outside the panel. There are no manufacturer redirects; only **Get directions** opens Google Maps.

Product images and specifications were retrieved from Ryoto's official website and its public catalogue API on 2 November 2026. `assets/models.json` records the source specifications. Coming-soon models are marked. NEXO's source range has no unit, so its range is listed as “Confirm in store”. Prices and local stock have not been supplied.

The showroom address is Ground Floor, C/36, Kankarbagh Housing Colony, Tempo Stand, near Kankarbagh Tempo Stand, Patna district, Bihar 800020. No phone number or opening hours were supplied.

Browser verification: Chrome desktop and mobile screenshots inspected; layouts and detail panels checked at 320, 390, 600, 768, 1024, 1440 and 1920 pixels. All sixteen detail panels, closing controls, expandable collection, external links, image loading and reduced-motion behavior passed.
